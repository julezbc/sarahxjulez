# sarahxjulez — unser Second Brain

Gemeinsames Gedächtnis von Sarah und Julez für Claude, aufgebaut nach dem „Second Brain von FPL Business“.

## Sarah: so legst du los

1. Einladung zum Repo auf GitHub annehmen (E-Mail oder https://github.com/notifications).
2. Auf https://claude.ai/code anmelden und GitHub verbinden: https://claude.ai/connect-github
3. Neue Sitzung starten, Repository **julezbc/sarahxjulez** auswählen.
4. Schreib: **/second-brain-interview**
   Claude zeigt dir, welche Blöcke schon erledigt sind, und geht mit dir den nächsten durch, eine Frage nach der anderen.
5. Am Ende: **/uebergabe**

Alles, was du oder Julez eingebt, wird automatisch committet und gepusht. Jede Sitzung holt sich zuerst den neuesten Stand.
